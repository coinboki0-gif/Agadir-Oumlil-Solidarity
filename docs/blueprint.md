# **App Name**: Agadir Oumlil Solidarity

## Core Features:

- Bilingual & RTL Homepage Display: Render all specified homepage sections in both Arabic (primary, RTL) and French (secondary), ensuring correct text direction, layout, and content for each language.
- Interactive UI Elements & Animations: Implement a sticky navigation with blur effect, scroll-triggered count-up animations for statistics, staggered entrance effects for program cards, glassmorphism UI elements, and subtle gradients for a dynamic and premium user experience.
- Responsive Multi-device Layout: Ensure the entire website is built with a mobile-first approach, providing a fully responsive design that adapts seamlessly and beautifully across all screen sizes and devices.
- Direct Donation Information & Quick Access: Display comprehensive banking details (Bank name, RIB, SWIFT) for direct donations, alongside a 'copy to clipboard' functionality for the RIB and clickable phone numbers for easy contact.
- Dynamic Content Rendering: Efficiently display all varied homepage content, including changing program descriptions, updated impact statistics, detailed project highlights, and heartwarming testimonials, enabling easy content updates.
- AI-powered Impact Story Writer tool: An internal tool leveraging generative AI to assist NGO staff in drafting compelling and emotionally resonant impact stories from provided beneficiary data or general notes for the testimonial section.
- Geographic Presence Integration: Integrate an interactive Google Maps link directly into the footer, allowing users to easily locate the NGO's base in Douar Anrouz, Taroudant Province.

## Style Guidelines:

- Primary Brand Color: A sophisticated Deep Teal (#0D4A5C) that evokes trust, stability, and growth. This color anchors the design, suitable for strong calls to action and foundational elements. (HSL: 191, 77%, 21%).
- Accent Color: A vibrant Golden Yellow (#D4A017) signifying hope, warmth, and generosity. Strategically deployed for prominent interactive elements, highlighted statistics, and key distinctions. (HSL: 40, 83%, 46%).
- Background Palette: A pristine White (#FFFFFF) provides a clean, open canvas for main content, thoughtfully complemented by a soft, warm gray (#F2F0EC) for section backgrounds and subtle contrast, enhancing readability and overall elegance. (HSL: 40, 8%, 95%).
- Arabic content will elegantly utilize 'Noto Sans Arabic' (sans-serif), chosen for its exceptional legibility and comprehensive support across various linguistic nuances. Note: currently only Google Fonts are supported.
- Latin content will employ 'Inter' (sans-serif), a contemporary and highly readable font, ensuring clarity and a modern aesthetic across headlines and body text. Note: currently only Google Fonts are supported.
- Modern, clean vector icons (e.g., medical cross, graduation cap, water droplet, mosque) rendered in either the Deep Teal or Golden Yellow palette, designed to be intuitive and reinforce the NGO's mission visually without clutter.
- Embrace a fluid, spacious layout characterized by full-width hero sections, a consistent mobile-first grid, and glassmorphism cards. This design prioritizes content hierarchy and a seamless user journey, accommodating Right-to-Left (RTL) flow for Arabic content.
- Subtle, non-intrusive animations powered by Framer Motion, including hero text fade-in, statistics counting up on scroll, and gracefully staggered program card entrances, adding a premium and engaging layer to the user experience.
